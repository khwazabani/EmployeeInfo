# empinfo

Spring Boot 3.3 (Java 17) REST service for employees, using MS SQL Server and Swagger/OpenAPI.

## Setup

1. Create the database in SQL Server:
   ```sql
   CREATE DATABASE empdb;
   ```
2. Edit `src/main/resources/application.properties` with your server, username and password.
   The `employee` table is created automatically (`ddl-auto=update`).
3. Run:
   ```
   mvn spring-boot:run
   ```

## URLs (context path `/empinfo`)

| What | URL |
| --- | --- |
| Swagger UI | http://localhost:8080/empinfo/swagger-ui.html |
| OpenAPI JSON | http://localhost:8080/empinfo/v3/api-docs |
| Employees API | http://localhost:8080/empinfo/api/employees |

## Employee JSON

```json
{
  "empName": "Asha Rao",
  "empDesignation": "Software Engineer",
  "empSalary": 750000.00
}
```

`empId` is generated by the database (identity column).

## Endpoints

| Method | Path | Purpose |
| --- | --- | --- |
| POST | /api/employees | Create |
| GET | /api/employees | List all |
| GET | /api/employees/{id} | Get one |
| PUT | /api/employees/{id} | Update |
| DELETE | /api/employees/{id} | Delete |
